# 白川郷 多言語・音声案内チャットボット

世界遺産・白川郷を訪れる外国人観光客向けに開発した、観光案内チャットボットです。
バスターミナルのタブレット端末で実際に運用されており、観光客は画面を押して話しかけるだけで、
6言語（日本語・英語・中国語・韓国語・スペイン語・フランス語）で案内を受けられます。

> このリポジトリは就職活動向けに公開用に整えた版です。
> 運用中の実データ（質問回答集の正データ、配信URL、サーバ設定）はサンプルに差し替えてあります。
> システムの設計とコードは運用版と同一です。

## 背景と課題

- 現地の観光案内では、外国人観光客への多言語対応が職員の大きな負担になっていた
- 一般的なLLMチャットボットをそのまま使うと、誤った案内（存在しない料金・時刻など）を
  自信ありげに答えてしまう危険がある
- 修了後も現地の職員だけで運用を続けられる仕組みにする必要がある

## システム構成

| ディレクトリ | 役割 |
|---|---|
| `webapp/` | 案内アプリ本体（Webアプリ）。音声認識→FAQ検索→回答表示・読み上げをブラウザ内で完結 |
| `admin/` | 職員向け管理画面（Streamlit）。質問回答集の追加・修正・翻訳・公開をブラウザで完結 |
| `server/` | AI回答の中継サーバ（PHP）。FAQで答えられない質問だけをLLMへ渡す |
| `tools/` | 質問回答集（Excel）からアプリ用データへの変換ツール、検索精度の評価ツール |
| `demo/` | 評価ツールが使う検索エンジンのPython再現版 |
| `assets/` | アプリが読み込むデータ（公開版ではサンプル） |

データの流れ:

```
管理画面 / Excel（質問回答集・正データ）
        ↓ tools/build_faq.py（検証つき変換）
     faq.json を配信
        ↓ 起動時に取得（失敗時は前回データで継続）
  案内アプリ（タブレット / スマートフォン）
```

## 設計上の工夫

### 1. 誤回答を防ぐ3段構えの回答順序

1. **FAQ検索**：職員が確認済みの質問回答集から探す（決まった答えはそのまま返す）
2. **AI回答**：FAQに無い質問だけを、参考資料を根拠としてLLMに答えさせる
3. **職員へ引き継ぎ**：どちらでも答えられない場合は、無理に答えず職員への案内を表示する

「答えられないことには答えない」ことを仕組みで担保し、誤答の害を最小化しています。

### 2. 言い換え辞書による検索の取りこぼし対策

観光客は登録した質問例と違う語で聞いてきます（「銀行ありますか」「鞄を置きたい」など）。
同義語辞書で入力文を補正してから照合する仕組みを入れ、効果を評価ツールで測定しました（後述）。

### 3. オフライン優先の端末動作

起動時は端末内のデータを即座に読み、裏側で最新データを取得します。
通信が失敗しても前回のデータで案内を続けられるため、現地の回線事情に左右されません。

### 4. 設置場所ごとの回答の出し分け

コインロッカーやATMのように案内所ごとに答えが違う質問には、
FAQの「設置場所」で回答を出し分けます（職員の選択 → 端末設定 → 位置情報の順に判定）。

### 5. 職員だけで運用が回るデータ設計

質問回答集はExcelを正データとし、管理画面とExcelのどちらからでも編集できます。
日本語を入れると他言語へ自動翻訳され、検証つき変換でデータ不整合を公開前に検出します。

## 評価（言い換え辞書の効果測定）

観光客が言いそうな言い方を集めた想定質問135件を `tools/eval/run_eval.py` で検索にかけ、
「正解／無回答（職員へ回した）／誤答（別の回答を返した）」を数えました。
誤答は、観光客が「答えをもらえた」と思って職員に聞く機会を失うため、最も避けるべき指標です。

| 条件 | 正解 | 無回答 | 誤答 |
|---|---|---|---|
| 言い換え辞書なし | 74.1% | 25.2% | 0.7% |
| 言い換え辞書あり | **92.6%** | 7.4% | **0%** |

（2026年11月27日、運用データ135件で測定。公開版では運用データを含めないため、
評価の再実行には正データが必要です。測定方法はコードで確認できます。）

## 技術スタック

- フロントエンド: JavaScript（フレームワークなし）、Web Speech API（音声認識・合成）
- AI中継: PHP、Claude API（Haiku 4.5）
- 管理画面: Python、Streamlit
- データ運用: Excel（正データ）、検証つき変換ツール（Python）
- 配信: 静的ホスティング＋GitHub上のデータ配信

## 動かし方

リポジトリ直下で簡易サーバを立て、`webapp/` を開きます（サンプルデータで動作します）。

```
python tools/serve.py
```

→ http://localhost:8000/webapp/
